# Каталог товаров электроники

Консольное приложение для работы с каталогом товаров магазина электроники. Программа позволяет:

- просматривать список товаров;
- искать товары по ID, названию, категории и диапазону цен;
- сортировать каталог по цене, рейтингу, дате выпуска и ID;
- покупать товар, если он есть на складе;
- добавлять, изменять и удалять товары в режиме администратора;
- сохранять и загружать каталог в текстовый файл.

## Основная идея

Приложение хранит данные о товарах в памяти, а также умеет читать и записывать их в текстовый файл. Это удобно для работы с каталогом без базы данных и позволяет быстро управлять ассортиментом.

## Структура проекта

- `main.py` — точка входа программы, запускает главное меню и управляет пользовательскими сценариями.
- `product.py` — модель данных товара.
- `products_functions.py` — логика поиска, сортировки, добавления, редактирования, удаления, сохранения и загрузки товаров.
- `console_helper.py` — вспомогательные функции ввода данных и вывода.
- `prod.dat` — файл с сохранённым каталогом товаров.


## Меню программы

### Меню покупателя
- поиск товара по ID;
- сортировка товаров;
- поиск товаров по параметрам;
- покупка товара;
- сохранение каталога в текстовый файл для печати.

### Меню администратора
- поиск товара по ID;
- добавление нового товара;
- изменение товара по ID;
- удаление товара по ID;
- загрузка товаров из файла;
- сохранение товаров в файл;
- сохранение товаров в файл для печати

## Пример использования

1. Запустить приложение.
2. Выбрать тип пользователя: покупатель или администратор.
3. Выполнить нужное действие в меню.
4. При необходимости сохранить данные в файл.

## Примечание

Проект реализован как учебное консольное приложение и демонстрирует базовые принципы работы с данными, функциями и пользовательским интерфейсом в Python.
